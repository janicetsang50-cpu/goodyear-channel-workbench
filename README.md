# 固特异汽车用品渠道运营管理工作台

这是一个可直接通过 GitHub Pages 发布的静态响应式工作台，包含：

- 首页经营驾驶舱
- 风险与待办任务区
- 七大核心模块导航
- ECharts 可视化图表
- 数据下载入口
- PPT 生成入口占位
- 手机端自适应布局

## GitHub Pages 发布方式

1. 在 GitHub 创建新仓库，建议命名为 `goodyear-channel-workbench`。
2. 上传本文件夹内全部文件。
3. 进入仓库 `Settings` → `Pages`。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/root`。
6. 保存后等待部署完成。

发布成功后的公网地址通常为：

`https://janicetsang50-cpu.github.io/goodyear-channel-workbench/`
